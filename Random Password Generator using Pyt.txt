Random Password Generator using Python

Description:
This project generates a random password based on the length entered by the user. It uses letters, numbers, and symbols to create strong passwords.

Features:
- Generates random passwords
- Uses letters, numbers, and symbols
- User can choose password length
- Beginner-friendly project

Technologies Used:
- Python
- random module
- string module

How to Run:
1. Open the Python file in IDLE
2. Press F5 to run
3. Enter password length
4. Get generated password
