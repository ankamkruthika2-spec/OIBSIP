Voice Assistant using Python

Description:
This is a beginner-level voice assistant project created using Python. It can respond to simple commands like hello, time, date, opening Google and YouTube.

Features:
- Greets the user
- Tells current time
- Tells current date
- Opens Google
- Opens YouTube

Technologies Used:
- Python
- pyttsx3
- datetime
- webbrowser

How to Run:
1. Open the project in Python IDLE
2. Run the file using F5
3. Enter commands in the shell
